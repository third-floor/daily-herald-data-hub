Workbook formats understood by this HTML

The page derives dates, title hierarchy, provisional categories, activity descriptions, basic place names, daily totals, intensity labels, broadcast text and seven-day summaries in the browser. It also recognises the enrichment outputs listed below when you add them later.

Sheet / columns Purpose Required?
records or first worksheet Raw archive records. Existing fields such as title, date, gem_date_flat, gem_depicted_activity, gem_places_depicted, gem_places_flat, url and image_links are recognised. Yes
place_gazetteer Reusable mapping table: raw_place, normalized_place, display_place, region, country, latitude, longitude, place_type, confidence. Needed for a reliable map
category_map Curated classification rules: match_type, match_value, primary_category, secondary_category, icon_key, colour. Recommended
Optional enriched record columns resolved_date, date_confidence, date_ambiguous, forecast_category_primary, forecast_category_secondary, activity_description, primary_place, normalized_place, region, latitude, longitude, place_confidence, forecast_eligible. Recommended for production
